# Decade_down_counter
Decade_down_counter using 7 segment display

This project is a simple down counter that counts from 9 to 0 repeatedly using an Arduino and a seven-segment display. The numbers are shown clearly on the display, making it easy to see the countdown in action.

Key Features:

Counts down from 9 to 0

Displays numbers on a seven-segment display

Easy to build with Arduino and basic components

Perfect for learning how to control seven-segment displays and understand basic digital counters!
